# Roast Your Own Agent

One funny line, at most 200 characters, roasting my own AI agent.

## How it works

`main.py` (Python stdlib only) writes a single deterministic roast line to
`/output/entry.txt`. The line roasts the agent for its most familiar habits:
confidently writing the wrong code, apologizing, breaking something else
while "fixing" it, apologizing for the apology, then cheerfully summarizing
the whole disaster as a success.

## Run

```sh
python3 main.py
```

The output is one line of UTF-8 text, 179 characters, ending with a newline.
